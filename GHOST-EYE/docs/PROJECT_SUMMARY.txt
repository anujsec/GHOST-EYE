NEW CAPABILITIES (SUMMARY)
========================================================================

FAST MODE (Default)
- ~5-15 minute runtime
- Passive subdomain enumeration
- DNS resolution
- HTTP probing
- Basic JavaScript analysis
- Lightweight URL crawling
- Simple secrets detection
- Nuclei scanning (basic tags)

DEEP MODE (--deep flag)
- ~30-60+ minute runtime
- All FAST mode features, plus:
- DNS brute force + permutations
- Deep crawling (Katana depth 3)
- Source map discovery
- API endpoint identification
- Content discovery (ffuf/feroxbuster)
- Port scanning (naabu)
- Service detection (nmap - optional)
- Extended Nuclei tags

AVAILABLE TOOLS (Auto-detected)
Required:
  - subfinder, httpx, nuclei

Optional (graceful fallback):
  - amass, dnsx, katana, gau, waybackurls
  - wamore (enhanced historical URLs)
  - ffuf, feroxbuster (content discovery)
  - naabu, nmap (port/service scanning)
  - alterx, puredns (DNS brute force)
  - arjun (parameter discovery)
  - jsluice (JavaScript analysis)
  - uro (URL normalization)
  - gowitness (screenshots)

INSTALLATION INSTRUCTIONS
========================================================================

1. INSTALL PYTHON DEPENDENCIES
   pip install -r requirements.txt

2. INSTALL REQUIRED TOOLS (Go-based)
   go install github.com/projectdiscovery/subfinder/v2/cmd/subfinder@latest
   go install github.com/projectdiscovery/httpx/cmd/httpx@latest
   go install github.com/projectdiscovery/nuclei/v3/cmd/nuclei@latest

3. INSTALL OPTIONAL TOOLS (For deep mode)
   go install github.com/projectdiscovery/katana/cmd/katana@latest
   go install github.com/lc/gau/v2/cmd/gau@latest
   go install github.com/ffuf/ffuf@latest
   go install github.com/projectdiscovery/naabu/v2/cmd/naabu@latest
   go install github.com/s0md3v/uro@latest

4. VERIFY INSTALLATION
   python3 -c "from tool_check import print_tool_status; print_tool_status()"

5. RUN FIRST SCAN
   python recon.py example.com
